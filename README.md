# IGTrendy — AI Prompt Community

Brand/domain: **igtrendy.in**

## Current MVP
- Responsive discovery homepage with glassmorphism / 3D-inspired ambient UI
- Search + category filtering
- Trending prompt gallery
- Prompt detail page + copy button
- Creator profiles
- Sign-in / upload flow UI
- Submission review/admin UI
- Messaging/community UI

## Next production phase
Connect Supabase for Auth, Profiles, Storage, Prompts, moderation, likes/views/copies, friends, realtime messages and notifications. Then add SEO pages, analytics and monetization.

## Run
```bash
npm install
npm run dev
```
